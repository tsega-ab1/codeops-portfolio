# Day 17 — Functions, Closures & Higher-Order Functions

## Files
- `order.js` — the deliverable module: `subtotal` (rest params + reduce),
  `discountBy` (factory), `withVat`/`toETB` (pure helpers), and
  `makeReceiptMaker()` (closure holding a private running order number).
- `run.js` — sample orders exercising the module.
- `expected.txt` — verified output; `node run.js` matches this exactly.
- `drills.js` — homework: `makeCounter`, `once` (closures), and
  hand-rolled `forEach`/`map` (callbacks).

## Concepts covered
- Function declarations vs expressions, arrow functions
- Closures and private state
- Higher-order functions: callbacks and factories
- Function composition
