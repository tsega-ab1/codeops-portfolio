# Day 12 — Forms, Tables, Media & Accessibility

## Files
- `index.html` — a reservation-style form (labels, `required`, `pattern`,
  `aria-describedby`), a styled data table, and an accessible image with
  `alt` text.

## Concepts covered
- GET vs POST, the `name` attribute, real `<label>` vs placeholder
- HTML validation attributes
- Accessible tables (`caption`, `scope`)
- Images, `figure`/`figcaption`, iframe `title`
