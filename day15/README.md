# Day 15 — Habesha Eatery (Week 1 Project)

## Files
- `index.html`, `styles.css` — a complete responsive static site for a
  fictional Ethiopian restaurant: sticky Flexbox navbar, fluid `clamp()`
  hero heading, about section, auto-fit menu grid, labelled/validated
  reservation form, footer with location and contact.

## Concepts covered
- Mobile-first responsive design, `min-width` media queries
- `clamp()`, fluid typography, `max-width: 100%` images
- Transitions (`transform`/`background`), `prefers-reduced-motion`
- The Week 1 deliverable — everything from Days 11–15 assembled into
  one shippable site
