# Day 19 — Addis Market Shopping List

A DOM/events project: an interactive shopping list where items can be added, marked bought, edited, deleted, and cleared in bulk. Starter items load from a local JSON file on page load.

## How to run
Open `index.html` in a browser (or serve the folder with a local dev server).

## Features
- Add items via a form (name + price)
- Click a row to toggle "bought" (strikethrough, excluded from total)
- Edit or delete individual rows
- "Clear bought" button removes all bought items at once
- Live item count and running total (ETB)
- Starter items (Teff, Berbere, Shiro) loaded from `starter-items.json` via `fetch` on page load
